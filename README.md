# Types of Sentences Quiz

## About the Project

This is a simple Quiz Application based on the four main types of sentences:

- Simple Sentence
- Compound Sentence
- Complex Sentence
- Compound-Complex Sentence

The quiz contains 10 multiple-choice questions.

## Features

- 10 quiz questions
- Multiple-choice options
- Correct answer message
- Incorrect answer message
- Selected option highlighting
- Attractive background
- User-friendly interface
- Responsive design for mobile devices

## Technologies Used

- HTML
- CSS

## How It Works

1. Select one option for each question.
2. The application checks whether the selected option is correct.
3. A "Correct" message is displayed for the correct option.
4. An "Incorrect" message is displayed for the wrong option.

## Files

### index.html
Contains the structure of the quiz, questions, options, and answer messages.

### style.css
Contains the styling of the quiz, background, heading, option boxes, and answer messages.

## How to Run

1. Keep `index.html` and `style.css` in the same folder.
2. Open `index.html` in a web browser.
3. Select an option to answer each question.
